## 📌 About This Project

This portfolio is a single-page website built to introduce who I am, highlight what I've worked on, and make it easy for recruiters and collaborators to get in touch.

## ✨ Features

- Clean, responsive layout that works on desktop, tablet, and mobile
- About, Skills, Projects, and Contact sections
- Downloadable resume
- Lightweight and fast, with no build step
